## 🔧 Реализованные функции

### 1. `double* full_elements(double *ptr_array, int n)`
- **Назначение**: Заполнение массива значениями
- **Параметры**: 
  - `ptr_array` - указатель на массив
  - `n` - размер массива
- **Возвращает**: указатель на заполненный массив
### 2. int put_elements(double* ptr_array, int n)
- **Назначение**: Печать элементов массива
- **Параметры**:
  - `ptr_array` - указатель на массив double
  - `n` - количество элементов для вывода
- **Возвращает**: количество выведенных элементов (n)
### 3. double* calc_elements(double* ptr_array, int n)
- **Назначение**: Обнуление всех отрицательных элементов массива
- **Параметры**:
  - `ptr_array` - указатель на массив double
  - `n` - количество элементов для обработки
- **Возвращает**: указатель на изменённый массив
### 4. double sum_elements(double* ptr_array, int begin, int end, int n)
- **Назначение**: Сумма элементов на заданном интервале [begin..end]
- **Параметры**:
  - `ptr_array` - указатель на массив double
  - `begin` - начальный индекс
  - `end` - конечный индекс
  - `n` - размер выделенной памяти
- **Возвращает**: сумму элементов или 0.0
### 5. int find_element(double* ptr_array, int n, double element)
- **Назначение**: Поиск первого вхождения элемента в массиве
- **Параметры**:
  - `ptr_array` - указатель на массив double
  - `n` - количество элементов
  - `element` - искомое значение
- **Возвращает**: индекс первого совпадения
### 6. double max_abs(double* ptr_array, int n, double A)
- **Назначение**: Максимальное по модулю значение, не равное A
- **Параметры**:
  - `ptr_array` - указатель на массив double
  - `n` - количество элементов
  - `A` - исключаемое значение
- **Возвращает**: максимум |x_i| где x_i <> A
### 7. double fa(double x)
- **Назначение**: Вычисление функции y = x²·π·cos(π·x)
- **Параметры**:
  - `x` - аргумент функции
- **Возвращает**: значение функции в точке x
### 8. int delete_negatives(double* ptr_arr, int size)
- **Назначение**: Удаление всех отрицательных элементов 
- **Параметры**:
  - `ptr_arr` - указатель на массив double
  - `size` - текущее количество элементов
- **Возвращает**: новое количество элементов после удаления отрицательных
### 9. double* insert(double* ptr_arr, int* size)
- **Назначение**: Вставка -999.0 после каждого положительного элемента
- **Параметры**:
  - `ptr_arr` - указатель на массив double
  - `size` - указатель на размер массива
- **Возвращает**: указатель на расширенный массив
### 10. double max_min_diff(double* ptr_array, int begin, int end, int n)
- **Назначение**: Разность максимума и минимума на интервале [begin..end]
- **Параметры**:
  - `ptr_array` - указатель на массив double
  - `begin` - начальный индекс интервала
  - `end` - конечный индекс интервала
  - `n` - физический размер выделенной памяти
- **Возвращает**: max-min на интервале
### 11. double* create_arr_d(double* arr_a, double* arr_b, double* arr_c, int size_a, int size_b, int size_c, int* size_d)
- **Назначение**: Создание массива D из трех массивов A, B, C по специальным правилам
- **Параметры**:
  - `arr_a, arr_b, arr_c` - исходные массивы double
  - `size_a, size_b, size_c` - их размеры
  - `size_d` - указатель на размер результирующего массива
- **Возвращает**: указатель на новый динамический массив d
### 12. double* generate_array(int* size)
- **Назначение**: Генерация случайного массива double случайного размера
- **Параметры**:
  - `size` - указатель на размер массива
- **Возвращает**: указатель на новый массив со случайными double [-50, +50]
### 13. void sort_insert(double* ptr_array, int n);
- **Назначение**: Сортировка вставками массива вещественных чисел по возрастанию
- **Параметры**::
  - `ptr_array` - указатель на динамический массив double для сортировки
  - `n` - количество элементов в массиве
- **Возвращает**: 0 при успешном выполнении
### 14. void sort_select(double* ptr_array, int n)
- **Назначение**: Сортировка выбором массива вещественных чисел по убыванию
- **Параметры**:
  - `ptr_array` - указатель на динамический массив double для сортировки
  - `n` - количество элементов в массиве
- **Возвращает**: 0 при успешном выполнении

### 15. void sort_bubble(double* ptr_array, int n)
- **Назначение**: Пузырьковая сортировка массива вещественных чисел по возрастанию
- **Параметры**:
  - `ptr_array` - указатель на динамический массив double для сортировки
  - `n` - количество элементов в массиве
- **Возвращает**: 0 при успешном выполнении
### 16. void sort_cocktail
- **Назначение**: Шейкерная (коктейльная) сортировка массива double по возрастанию
- **Параметры**:
  - `arr` - указатель на динамический массив double для сортировки
  - `size` - количество элементов в массиве
- **Возвращает**: 0 при упешном выполнении
